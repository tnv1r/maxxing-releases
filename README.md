# Maxxing desktop downloads

Download the latest release without a GitHub account:

**[Download Maxxing](https://github.com/tnv1r/maxxing-releases/releases/latest)**

| Platform | Package |
| --- | --- |
| Apple Silicon Mac | Signed and notarized DMG |
| Windows x64 | Unsigned portable ZIP |
| Linux x64 | AppImage; X11 activity tracking, Wayland timer only |

Choose your package under Assets. Checksums are included in each release.

This repository hosts public release files only. Application source is maintained privately. Releases are published manually; this repository has no build workflows.
